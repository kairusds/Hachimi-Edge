# 기능
- **번역 패치:** 손번역이기 떼문에 고품질입니다.

    지원 대상:
    - UI 
    - master.mdb (스킬 이름, 정보, 등.)
    - 해설
    - 스토리
    - 가사

    다언어 지원

- **쉬운 설정:** 추가적인 짓거리 하실 필요 없습니다.
- **자동 번역:** 자동 업데이트,재시작 불필요
- **인개임 GUI:** config 번경후 재시작 불필요.
- **품질 번경:** 그래픽 리미터 해제.
- **크로스 플랫폼:** 그냥 아무 기기에서나 다 된다는 소리입니다.
